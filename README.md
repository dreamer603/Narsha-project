# OASIS SURVIVOR
![StartScene](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Title.png)

오아시스 서바이벌은 뱀서라이크 장르의 3D PC 게임입니다.

게임은 일반 스테이지와 보스 스테이지로 나뉘어 있습니다.

![NormalScene](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Normal.png)
![ChoiceSkills](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Skills.png)

일반 스테이지는 3인칭 시점의 뱀서라이크 형식으로 진행되며, 플레이 중 레벨업을 통해 다양한 스킬을 선택할 수 있습니다.

![BossScene](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Boss.png)

보스 스테이지는 1인칭 시점의 소울라이크 형식으로 진행됩니다.

홈 화면에서는 플레이 중 얻은 재화로 유저의 스탯을 높일 수 있습니다.

## 사용 기술

- Unity 3D, C#
- Notion, GitHub
- Photoshop
